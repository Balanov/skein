THE MECHANISM

Cancellation is not enough.

A canceled task can still finish. Skein checks its epoch again before accepting the result, so stale output never unlocks dependent work.

lease / epoch / sequence

Dispatch with a lease

STOP → epoch + 1

Stop advances the epoch

stale ≠ accepted

Late results are fenced

Reset never reuses an old epoch.
